# Customer Segmentation

An unsupervised machine learning project that segments customers into distinct groups using K-Means clustering, accompanied by an interactive Streamlit web application for visualization and demonstration.

## Overview

This project performs customer segmentation by applying clustering techniques to identify unique customer groups. The solution includes comprehensive data preprocessing, feature engineering, exploratory analysis, K-Means clustering, and the creation of interactive visualizations. A Streamlit application was built to demonstrate the segmentation results and allow users to explore different customer clusters.

## Project Workflow

- Performed data preprocessing, including cleaning, handling missing values, and feature scaling.
- Conducted exploratory data analysis to understand customer behavior and distributions.
- Applied feature engineering to enhance clustering performance.
- Implemented K-Means clustering to group customers into meaningful segments.
- Generated interactive visualizations to highlight distinct customer groups and cluster characteristics.
- Built and deployed a Streamlit web application to showcase the segmentation model interactively.

## Results & Impact

- Designed and trained a K-Means clustering model to perform customer segmentation.
- Delivered an interactive Streamlit application that enables stakeholders to explore and visualize customer segments in real time.

## Technologies & Tools

- **Programming Language**: Python
- **Core Libraries**:
  - scikit-learn (for preprocessing and K-Means clustering)
  - Streamlit (for building the interactive web application)

## Techniques & Skills Demonstrated

- K-Means clustering for unsupervised segmentation
- Data preprocessing with `StandardScaler`
- Feature engineering for improved cluster quality
- Interactive data visualization
